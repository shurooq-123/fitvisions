# Image editing and mobile readiness

Uploaded clothing and optional face photos open an editor before use. Users can retain the original, crop by dragging, set output pixel dimensions with optional aspect lock, add text/arrows, undo marks, and save a new PNG. Originals are preserved. Editing is local; the accepted image can subsequently be sent to the AI workflow. Camera/album permissions remain managed by the platform picker.

Appearance uses sun/moon controls; language uses labelled choices; history sorting uses directional arrows and short labels. Existing navigation and app colour palette are retained.

Verified locally: raster crop/resize and arrow output; existing regression suite. Physical phone interaction and accessibility screen-reader review still require device verification.

Remaining production basics: real payment gateway and server-side payment verification; hosted always-on AI/mail/push services; visible privacy/data-retention policy and user account deletion request flow; production signing/release distribution. These are not represented as completed by this UI change. Existing authentication, validation, profile/history, language/theme persistence and notification UI do not alone prove production readiness.
